## What it actually is

'A rendering engine for reality' — separates physical geometry from visual interpretation so the same real environment can be re-rendered through Reality Packs (1812, 1500s, 3055, solarpunk, museum mode, blueprint mode, low-stimulation mode…). Pipeline: Reality Capture → Understanding → Interpretation → Rendering → Display, with phones first and AR glasses later. Extensive docs set (vision, MVP blueprint, era pack format, stack, machine capabilities, roadmap) plus research notes on AR SDKs, scene understanding, and AI generation pipelines. Engine/runtime/tools/demos folders are scaffolded; this is a documented architecture awaiting build.
