## What it actually is

Jaron's persistent public media library: upload a screenshot once and any AI or human can reference it forever via raw.githubusercontent URLs — no re-uploading into chats. Includes gallery.html (visual browser) and a mobile upload panel that pushes photos from a phone browser via the GitHub API.
