## What it actually is

A mobile-first Perspective/Framing exercise app spec that converts ambiguous prompts into descriptive response patterns (deliberately NOT scores — the creator's honesty note about accidentally using 'scoring' language is part of the README). Docs set covers prompt set v3, policy model, 'scoring' engine, wireflow, data model, routes/API and output modules. A v0.dev Vercel project (v0-framing-lens-project) exists but has no deployments — the app has not shipped; the spec is the artifact. Forked to the SpaceYouLand org.
