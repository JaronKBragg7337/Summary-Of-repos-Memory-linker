## What it actually is

'Hiring compatible AIs to work for you' — a self-documenting recurring-task system that runs entirely from consumer AI apps (Grok, ChatGPT, Perplexity, Claude) on phone/web subscriptions: no API, no server, no code. On a schedule the workers read the operator's live public signals, produce and advance work, propose value, cross-check each other across models, restyle a public surface daily, and write everything to an open record. README is the front door; SPEC.md the full specification; STATUS.md the verified build state (kept in sync with a Google Drive canonical copy).
