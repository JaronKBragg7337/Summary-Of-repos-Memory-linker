## Enter the 3D world

Open **[`index.html`](index.html)** (serve the repo root or enable GitHub Pages). It's a Three.js data center:

- **Server racks** = games & 3D worlds · **The ZEUS mainframe** = zeus-ai · **Cooling units** = agent/heartbeat systems · **Storage arrays** = memory & substrates · **Network switch wall** = bridges & tools · **Tape libraries** = writings & theory · **Control console** = this repo
